## 📚 O que aprendi

- ✔ Como revisar um Pull Request antes de aprová-lo.
- ✔ Como adicionar comentários em linhas específicas do código.
- ✔ Como sugerir alterações utilizando o recurso **Suggested Changes**.
- ✔ Como aprovar ou solicitar mudanças em um Pull Request.
- ✔ A importância da revisão de código para manter a qualidade do projeto.
- ✔ Como funciona o fluxo de colaboração entre desenvolvedores utilizando Pull Requests.
