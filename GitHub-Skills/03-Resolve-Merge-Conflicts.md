## 📚 O que aprendi

- ✔ O que são conflitos de mesclagem (Merge Conflicts) e por que eles acontecem.
- ✔ Como identificar quando um Pull Request possui conflitos.
- ✔ Como utilizar o editor web do GitHub para resolver conflitos manualmente.
- ✔ Como decidir quais alterações devem ser mantidas durante a resolução de um conflito.
- ✔ Como concluir um Merge após resolver todos os conflitos.
- ✔ A importância da comunicação e da colaboração para evitar conflitos em projetos com vários desenvolvedores.

---

## ⚠️ Dificuldades encontradas

No início tive dificuldade para compreender por que os conflitos de mesclagem aconteciam, já que parecia que todas as alterações poderiam ser unidas automaticamente.

Durante o curso, entendi que os conflitos surgem quando diferentes alterações são feitas na mesma parte de um arquivo. Também aprendi a utilizar o editor do GitHub para analisar cada alteração e escolher a versão correta antes de concluir o Merge.
