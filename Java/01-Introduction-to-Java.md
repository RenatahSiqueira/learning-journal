## 💻 Primeiro exercício

Para praticar os tipos de variáveis, criei um programa utilizando informações de um animal.

Foram utilizadas variáveis para representar:

- `String` → nome
- `int` → idade
- `double` → peso
- `char` → inicial
- `boolean` → estado de saúde
- `byte` → quantidade de alimentações por dia

Exemplo utilizado:

```java
String nome = "Barão";
int idade = 9;
double peso = 320.4;
char inicial = 'B';
boolean estaSaudavel = true;
byte alimentacoesNoDia = 2;
```

Também utilizei `System.out.println()` para exibir os valores no terminal.
